# gecioptparse

R package wrapping `optparse` with typed option builders and a named-option registry, standardizing command-line argument parsing across R projects.

## Identity

Package name is **`gecioptparse`**, not `optparse`. Use `library(gecioptparse)` or `gecioptparse::get_options()`.
Dependencies: `optparse`, `tidyverse`, `R6`, `comprehenr`.

## All work happens in Docker

```sh
docker compose run islasgeci make <target>
```

The image (`islasgeci/optparse`) is built from `Dockerfile`, repo mounted at `/workdir`.

## Make targets

| Target | What it does |
|--------|-------------|
| `tests` | `devtools::test(stop_on_failure = TRUE)` |
| `check` | Style check with `styler` (R/ and tests/) |
| `format` | Auto-format R/ and tests/ with `styler` |
| `coverage` | Tests + `covr` report (`make setup` first) |
| `install` | `devtools::document()` → `R CMD build` → `R CMD check` → `R CMD INSTALL` |
| `setup` | `clean` + `install` |
| `clean` | Remove `*.tar.gz`, `NAMESPACE`, test snapshots |
| `red` / `green` / `refactor` | TDD cycle (format → test → conditional commit) |

## TDD targets

These auto-commit based on test outcome:
- `make red` — commit test files on failure (`🛑🧪` prefix)
- `make green` — commit R/ files on pass (`✅` prefix)
- `make refactor` — commit R/ + test files on pass (`♻️` prefix)

## Generated files

- `NAMESPACE` and `.Rd` files — generated by `devtools::document()` via `roxygen2`, not in git
- RoxygenNote 7.2.1 (see `DESCRIPTION`)

## Entrypoints

- `get_options()` — all default CLI options (`R/option_parser.R`)
- `character_option()`, `integer_option()`, `double_option()` — typed option builders (`R/builder_options.R`)
- `get_options_from_names(names)` — select from predefined `OPTIONS` registry (`R/named_options.R`)
- `get_options_from_vec(vector)` — parse arbitrary option list (`R/get_option_from.R`)

## Testing

- `testthat` edition 3; runner at `tests/testthat.R`
- Tests use BDD-style `describe()` / `it()` blocks
- CLI invocations are built with `glue::glue()` and executed via `system()`
- Helper scripts in `tests/helpers/` are exercised via `Rscript` in tests
